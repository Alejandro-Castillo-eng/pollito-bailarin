# Pollito Bailarín 🐣

Tiendita kawaii en Perú: Sanrio, Sylvanian Families, Chiikawa, blind boxes, peluches y papelería.

- Escena 3D del pollito bailarín y vitrina 3D giratoria hechas con [Three.js](https://threejs.org/).
- Catálogo con filtros y pedido que se envía por WhatsApp.
- Sitio estático: HTML, CSS y JavaScript, sin paso de compilación.

## Ver en local

Doble clic en `iniciar.bat` (abre `http://localhost:8080`), o:

```bash
python -m http.server 8080
```

## Editar productos

Precios, stock, fotos y videos están en `js/productos.js`.
